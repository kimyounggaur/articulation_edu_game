# 눈길 발자국

펭귄의 걸음·자국·소리로 스타카토, 레가토, 악센트, 테누토, 마르카토를 배우는 음악 수업용 웹앱입니다.

## 실행

Node.js 22.12 이상(이 작업은 24.22.1)을 사용합니다.

```sh
npm ci
npm run dev
npm run check
```

`npm run check`는 29개 시험, TypeScript strict, ESLint, Next.js 정적 내보내기를 실행합니다. 최종 배포 디렉터리는 `out/`입니다. 서버·로그인·분석 요청은 없습니다. 글꼴은 npm에서 함께 빌드되며 실행 중 외부 글꼴 요청이 없습니다.

## 이용

- 6개 안내 미션과 18개 문제 미션(본 문제 99개), 선택 귀로 맞히기(6문제), 자유 눈길(12가락)
- 오답 3단계 도움, 최대 2문제 재도전, 별과 기호별 기록
- 수업 링크: `?open=3&sound=off`. 임시 구간·소리는 영구 기록을 바꾸지 않습니다.
- `snowpath.v1`에 완료 기록·소리 선호만 저장합니다. 진행 중 미션은 새로고침하면 중단됩니다.
- 개발용 `/lab/`, `/lab/viewport/?width=360&height=640`는 배포 출력에서 제거됩니다.

## 제공 자료와 검증 한계

원본 자료 4개는 `docs/`에 보관했습니다. 프롬프트가 전제한 `snowpath-kit.zip`의 참조 엔진, 19개 원본 시험, 골든 JSON, 독립 Python 생성기는 제공되지 않았습니다. 이 구현의 엔진은 기획서 1.0과 시안에서 재구성했습니다. 원본 골든 자료와 동일하다고 주장하지 않습니다. 재구성 엔진은 1,732개 유효 상태 전체, 113개 문제 틀과 19개 문제 미션 × 100개 씨앗의 규칙을 시험합니다.

기획서에 누락된 §9.8의 버튼 문구 표는 화면 설명과 프롬프트에서 복원했습니다. 글꼴은 빌드 시 외부 Google Fonts 접속 의존을 줄이기 위해 self-hosted Fontsource 패키지를 사용합니다. 도형 펭귄은 첫 버전 확정 범위이며 선택 그림 교체/PWA는 포함하지 않습니다.

아이폰·안드로이드 실물 기기의 스피커, 악센트/마르카토 청감 차이, 아이폰 무음 스위치 확인은 아직 수행하지 않았습니다.

악보 윤곽선은 제공된 시안의 Bravura 경로를 사용합니다. 전체 라이선스는 `public/OFL-Bravura.txt`, 설정 화면에 있습니다. 폰트 라이선스도 `public/`에 동봉합니다.
