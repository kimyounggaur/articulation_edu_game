# 눈길 발자국 — 그림 제작 목록

버전 1.0 · 2026-11-16 · 기획서 1.1의 13장 기준

## 0. 이 문서

- 쓰임: 임시 그림(도형으로 그린 펭귄과 눈길)을 나중에 바꿀 때 만들 그림의 목록이다. 프롬프트 설계서의 선택 단계 A에서 쓴다.
- 그림이 없어도 앱은 도형 그림으로 완성된다. 일부만 만들어도 된다. 없는 그림은 도형 그림이 그대로 쓰인다.
- 표지판 단추의 기호 그림(점, 줄, 이음줄, `>`, `^`)은 악보 기호 그대로 쓰고 바꾸지 않는다.
- 눈 위의 자국은 앱이 그린다. 그림에 넣지 않는다(구간 그림은 예외).
- 이 목록의 크기와 기준점은 설계한 값이다. 실제 그림을 넣어 화면에서 확인해 보지 않았다.

## 1. 공통 조건

| 항목 | 조건 |
|---|---|
| 그림체 | 단순한 도형과 평평한 색. 그러데이션, 그림자, 질감, 외곽선을 쓰지 않는다 |
| 색 | 몸 남색 #1B2145, 배와 쌓인 눈 흰색 #FFFFFF, 부리와 발 주황 #F28A3C, 목도리 #E4572E, 그늘진 눈밭 #E9EEF8, 옅은 선 #C9D2EA |
| 방향 | 펭귄은 오른쪽을 본다(걷는 방향이 오른쪽이다) |
| 바탕 | 펭귄, 별, 맞음·틀림 표시, 구간 그림은 투명 바탕 |
| 형식 | PNG(투명) 또는 SVG. 둘 다 되면 SVG가 낫다(확대해도 깨지지 않는다) |
| 글자 | 그림 안에 글자를 넣지 않는다 |
| 권리 | 직접 만들었거나 쓸 권리가 있는 그림만 쓴다. 기존 작품의 펭귄 캐릭터를 닮게 만들지 않는다 |

그림 만드는 도구에 넣을 때 앞에 붙이는 공통 문구

```text
Flat vector illustration, simple geometric shapes, solid colors only, no outlines, no gradients, no shadows, no texture, no text. Palette: navy #1B2145, white #FFFFFF, orange #F28A3C, red-orange #E4572E, pale blue #E9EEF8. Transparent background.
```

## 2. 펭귄 (자세 4개)

- 캔버스는 480×480. 발이 눈에 닿는 곳이 기준점이고 자리는 (240, 440)이다. 가로 가운데, 아래에서 40 위.
- 펭귄의 키는 캔버스 높이의 75%쯤(약 360). 네 그림에서 몸의 크기와 색이 같아야 한다.
- 뜨는 높이, 눌림, 옆으로 가는 움직임은 앱이 만든다. 그림은 자세만 다르게 그린다.

| 파일 | 자세 | 쓰이는 때 | 그릴 때 지킬 것 |
|---|---|---|---|
| `penguin-stand.png` | 서기 | 출발 전, 도착 뒤, 보통 걸음으로 디디고 있을 때 | 두 발이 기준점의 양옆에 닿아 있다 |
| `penguin-jump.png` | 뜀 | 소리가 멎은 틈(공중) | 날개를 조금 벌리고 발을 모은다. 발끝이 기준점 높이에 오게 그린다 |
| `penguin-land.png` | 착지 | 세게 디딜 때(쿵, 쾅), 끝까지 누를 때(꾹) | 무릎을 굽혀 몸이 조금 납작하다. 두 발이 기준점의 양옆에 닿아 있다 |
| `penguin-slide.png` | 미끄러짐 | 이어 갈 때(스르륵) | 배를 대고 엎드려 머리가 오른쪽을 향한다. 배의 가장 아래가 기준점에 닿는다 |

제작 문구 (공통 문구 뒤에 붙인다)

```text
A small cute penguin character facing right, navy body, white belly, orange beak and feet, wearing a short red-orange scarf. Pose: standing upright with both feet on the ground. Full body, centered, feet at the bottom.
```

```text
Same penguin, same proportions and colors. Pose: jumping in the air, flippers slightly spread, feet tucked together.
```

```text
Same penguin, same proportions and colors. Pose: landing with bent knees, body slightly squashed, both feet flat on the ground.
```

```text
Same penguin, same proportions and colors. Pose: sliding on its belly toward the right, head forward, flippers back.
```

## 3. 눈길 배경

| 파일 | 크기 | 내용 |
|---|---|---|
| `lane-bg.png` | 1044×342 | 눈길의 배경. 바탕이 투명하지 않아도 된다 |

- 눈의 표면(펭귄이 딛는 선)은 위에서 186 되는 곳이다(높이의 54%). 가로로 거의 평평해야 한다.
- 표면 아래(186~342)는 자국이 그려지는 곳이다. 무늬 없이 흰색 또는 아주 옅은 색 한 가지로 둔다. 자국(남보라 #5B6CC4)이 또렷하게 보여야 한다.
- 표면 위(0~186)는 펭귄이 걷는 곳이다. 먼 언덕이나 나무를 옅은 색으로만 그린다. 진한 색을 쓰지 않는다.
- 네 모서리는 앱이 둥글게 자른다.

```text
Wide winter landscape strip, aspect ratio about 3:1. Lower 46% is plain flat white snow with no details. Upper 54% is a very pale blue sky with faint distant snowy hills and a few tiny pale trees. Very low contrast, calm, empty foreground.
```

## 4. 구간 그림 (홈의 카드, 6개)

- 크기는 480×320. 투명 바탕.
- 구간마다 그 걸음의 자국이 눈 위에 보이게 그린다. 자국의 모양은 기획서 4장의 표와 같게 한다.

| 파일 | 구간 | 그림 |
|---|---|---|
| `stage-1.png` | 톡톡 길 (스타카토) | 점처럼 짧은 자국 네 개. 발끝으로 뛰는 펭귄 |
| `stage-2.png` | 스르륵 길 (레가토) | 끊기지 않고 길게 이어진 자국. 배로 미끄러지는 펭귄 |
| `stage-3.png` | 쿵 길 (악센트) | 굵게 시작해서 가늘어지는 자국. 발을 구르는 펭귄 |
| `stage-4.png` | 꾹꾹 길 (테누토) | 한 칸을 꽉 채운 막대 자국이 틈을 두고 네 개. 눌러 걷는 펭귄 |
| `stage-5.png` | 쾅 길 (마르카토) | 가장 굵은 자국과 둘레에 튄 눈. 높이 뛰어 내려찍는 펭귄 |
| `stage-6.png` | 눈길 끝까지 | 여러 자국이 섞인 긴 길. 멀리 도착 깃발 |

## 5. 별과 표시

| 파일 | 크기 | 내용 | 지킬 것 |
|---|---|---|---|
| `star-on.svg` | 48×48 | 얻은 별 | 속이 찬 별. 색은 #E4572E |
| `star-off.svg` | 48×48 | 아직 얻지 못한 별 | 테두리만 있는 별. 색은 #C9D2EA |
| `mark-ok.svg` | 32×32 | 맞음 | 동그라미 안의 ✓. 색은 #147A5E. ✓ 모양을 바꾸지 않는다 |
| `mark-no.svg` | 32×32 | 틀림 | 동그라미 안의 ✗. 색은 #B23A2B. ✗ 모양을 바꾸지 않는다 |

맞음과 틀림은 색을 구분하기 어려운 사람도 알아볼 수 있게 모양으로 구분한다. 그래서 ✓와 ✗의 모양은 그대로 둔다.

## 7. 넣는 곳과 확인표

- 넣는 곳: `src/art/` 폴더. 파일 이름은 표와 같게 한다.
- 넣은 뒤 프롬프트 설계서의 선택 단계 A를 진행한다.

| 확인 | 내용 |
|---|---|
| ☐ | 파일 이름과 크기가 표와 같다 |
| ☐ | 펭귄 네 그림의 기준점이 (240, 440)이고 몸의 크기와 색이 같다 |
| ☐ | 펭귄이 오른쪽을 본다 |
| ☐ | 펭귄, 별, 표시, 구간 그림의 바탕이 투명하다 |
| ☐ | 눈길 배경의 표면이 위에서 186 되는 곳에 있고 그 아래가 한 가지 옅은 색이다 |
| ☐ | 그림 안에 글자가 없다 |
| ☐ | 앱에 넣은 뒤 자유 눈길에서 발이 눈 표면에 닿아 있고 자국이 또렷하다 |
